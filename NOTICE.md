## Data and Images

The repository includes vehicle registration code data, flag images, and license plate example images. These materials are compiled from the sources listed in the README and from the source URLs stored in the data files.

Mirrored images under `public/images/` are included so the app can load reliably and support offline use. They remain subject to the copyright, license terms, and attribution requirements of their original sources.

Source URLs are preserved in:

- `src/data/current-license-plates.json` for overview flag sources
- `src/data/countries/en/*.json` for license plate example image sources

Before reusing images or data outside this project, check the original source URL and follow the license or terms published there.

## Corrections

If an image, source, attribution, or license note appears incorrect, please open an issue or pull request with the corrected source information.
